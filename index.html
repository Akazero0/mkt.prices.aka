Identificar producto

En iPhone, permite el acceso a la cámara cuando Safari lo solicite. Si el escáner no es compatible, escribe el código o usa la búsqueda por foto.
La foto se usa como referencia visual en este prototipo. No hay reconocimiento automático de texto integrado todavía; puedes completar el nombre y la marca manualmente.

Datos del producto

Registrar precio observado

Los precios manuales quedan marcados como observados. La fecha permite detectar registros antiguos.

Comparar precios

Los resultados solo incluyen precios registrados en este dispositivo. Los enlaces de búsqueda permiten comprobar precios publicados; no representan una integración automática con los inventarios de las cadenas.

Buscar precios online

Abre una búsqueda web del producto en cada supermercado. Confirma formato, sucursal, despacho y requisitos de membresía antes de comparar.

Productos guardados

Privacidad y almacenamiento

Este prototipo guarda los datos en el almacenamiento local del navegador de este dispositivo. No se crea una cuenta ni se sincronizan automáticamente los datos con otros equipos. Si borras los datos de Safari, podrías perderlos; exporta respaldos periódicamente.
